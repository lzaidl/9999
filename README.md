## التشغيل على الكمبيوتر
```bash
npm install
npx expo start -c
```
ثم افتح المشروع في Expo Go.

## مهم جداً عند استخدام Expo Snack
Snack يحتاج أن تكون dependency مضافة للمشروع نفسه. من Dependencies أضف:
`expo-image-picker` بالإصدار `17.0.11`.

إذا كنت تستورد ZIP إلى Snack ولم تظهر Dependencies، لا تلصق App.js فقط؛ استخدم مشروع Snack وأضف dependency يدوياً. الخطأ `Unable to resolve module 'expo-image-picker.js'` يعني أن Snack لم يجد الحزمة، وليس أن كود ImagePicker نفسه مفقود.
